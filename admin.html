Supabase PostgreSQL Live Connection

Connect your static GitHub Pages site directly to a free Supabase cloud database. Credentials are saved locally in your browser so you never need to commit sensitive keys to git.

Quick Supabase Setup:
  1. Create a free project at supabase.com.
  2. Copy the contents of supabase-schema.sql into your Supabase SQL Editor and click "Run".
  3. Copy your Project URL and anon public API Key into the fields above and click Save.
